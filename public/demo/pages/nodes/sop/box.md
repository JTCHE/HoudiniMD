## Overview

Box makes a six-sided box. Connect geometry to its input, and the box fits around that geometry instead: a quick way to see the size of a model, or to make a collider for it.

## Parameters

| Parameter | Description |
| --- | --- |
| Primitive Type | Polygons, a polygon mesh, or a mesh of NURBS. |
| Size | The length of the box on each axis. |
| Center | The middle of the box. |
| Rotate | Turns the box around its middle. |
| Uniform Scale | Scales the whole box by one number. |
| Axis Divisions | How many faces each side gets. |
